#Welcome to my music app, created using Electron.js!

It's just a very simple app designed to play music. 
It comes with pause/play, rewind and fast-forward capabilities, as well as timeline shifting.

**Installation:**
Firstly, install all the node modules with npm i.
Then just run npm start and a window should open!

**Additional info:**
There are only a few songs at the moment, using local mp3s. if you'd like to extend the playlist, add in your own mp3s and follow the format of the array!
