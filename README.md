
# ElectronJS Music Player App

## Description
Welcome to my music app, created using Electron.js!

It's a small application designed to play music. 

It comes with pause/play, rewind and fast-forward capabilities, as well as timeline shifting.

## **Installation**
Firstly, install all the node modules with **npm i**.

Next, run **npm start** and a window should open with the app!

## **Additional info**
There are only a few songs at the moment, using local mp3s. If you'd like to extend the playlist, add in your own mp3s, following the format of the array!
